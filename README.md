# 濟生醫院記（漢文首篇，東京大學總合圖書館 V10:413）

*Saisei iin ki [First Kanbun Account of Saisei Hospital]*

《濟生醫院記》首篇為日本明治時期漢文院記，記下總國海上郡荒野村濟生醫院的成立，提及淺田宗伯及其門人，也陳述漢醫與西醫在明治醫療制度變動中的關係。篇末署年為 1886 年，現存抄本的確切抄年未詳。

本版收漢文首篇至署款「識」，共四個書面區、34 欄。提供逐欄及連讀 TXT、JSON、TEI P5 與原圖定位。以兩份 AI 影像初稿比對並回圖，疑讀留候選。尚無人類全文雙校、專家審定或準確率量測。
